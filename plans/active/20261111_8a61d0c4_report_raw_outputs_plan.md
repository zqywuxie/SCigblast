## 已核查的问题

- `analysis/repertoire/assets/report.js` 的 `comparisonUnits()` / `comparisonNode()` 将 Raw 和 Mapping 引物构成固定配成两栏，缺项仍创建空位。新统计已使用 `primer_matching_source=raw_R1`，展示兼容分支仍需收敛。
- `charts.js` 的 `outputs()` 为多链数据生成三个图，`report.css` 的 `.output-panels` 强制三列，每图另设最小宽度和滚动条。所有柱都显示数值，导致多链小值重叠。PNG 导出与 Python 静态产图也采用横向三图。
- 远端任务 `7949d80093784205`，结果根目录 `/colddata/SCigblast/results/SCigblastWeb/Admin_b36c9f1e/igblast_base/pig/20261110_112428`，报告 `analysis/reports/e5dec9daf3e9`。
- 原始 manifest 保留 `TCRα-1/2`、`TCRβ-1/2`，fastp 汇总的 sample 却归一为 `TCR_-1/2`。`scigblast/stage_metrics.py` 仅按样本/配对身份精确匹配或 basename 匹配，无法关联后排除了这些计数。
- 四个 TCR 的 Raw 文件存在，fastp JSON 存在，实际输出有不同的哈希子目录。例如 `TCR_-1-4bebda398e89` 与 `TCR_-1-d9c9100aaad0`。未发现文件覆盖证据。本次未扫描全部 FASTQ，也未执行完整生物学结果复核。

## 实施顺序

### 1. 总览只展示 Raw 引物匹配

- 总览仅选择明确标记为 `raw_R1` 的统计与存疑组比较，分母保持样本全部原始 `_j` reads。
- 取消总览的阶段选择及 Raw/Mapping 配对容器，Raw 占满可用宽度。
- MIX 仍用所选链引物并集匹配，同一来源去重，不累加重复 Raw。
- 历史报告有 Raw 则展示 Raw。只有 Mapping 或阶段身份不明则明确 Raw 统计不可用，不能改标签冒充 Raw。
- 同步图清单、统计口径与当前图 PNG/CSV 导出范围。历史底层表保留，不删除其他模块依赖的数据。

主要文件：`analysis/repertoire/assets/report.js`、`report_html.py`、`chart_data.py`、`report_rules.py`。检查 `render.py` / `render_matching.py` 的静态图与清单兼容性。

### 2. 样本产出布局

- 三个指标按全宽上下排列，使用可见英文图题。保留单指标切换。
  1. Total Reads，Merged 后数量，每个样本共享输入只画一次。
  2. Total Receptor RNA，各链分别显示 AIRR 后处理 copy/umi_counts。
  3. Total Unique CDR3s，各链分别显示唯一 CDR3，不能将各链去重数直接视为样本全局去重数。
- 三图使用同一批样本、同一顺序与共同分页，默认每页最多 6 个样本。链颜色固定，不因筛选改变。
- 单链和多链均采用同样的指标排列，各指标独立纵轴，避免数值量级遮蔽。
- 常规宽度取消三个独立横向滚动条。小屏根据空间收缩分页，必要时使用一个同步滚动区域，不截断坐标与图例。
- 稀疏时保留数值标签，密集时隐藏重叠标签；悬停和 CSV 始终保留精确值。零值、缺失值、未选择链区分处理。
- 修正产出图 tooltip 中无 primerGroup 时出现 undefined 的问题。缺失提示按当前页范围展示，共享输入缺失按样本去重。
- 交互 PNG 改为纵向组合，Python 静态图与备用展示保持一致。图题当前代码已有配置，实施时核查实际浏览器中的可见性，不预设缺失原因。

主要文件：`analysis/repertoire/assets/charts.js`、`assets/report.js`、`assets/report.css`、`output_metrics.py`、`chart_data.py`。调整页码、图数预算及静态清单，避免全样本图和链级图重复展示。

### 3. 修复阶段计数身份关联

- 原始 sample_id、pair_id 与文件系统安全名称分离。新 fastp 汇总保存原始身份和稳定输入/输出关联，不能把脱敏名称当主键。
- 对现有 Base 结果，从 Match manifest、已声明布局和准确 stage-relative/hash 目录建立唯一映射，验证 JSON 归属与所选数据集范围。
- `stage_metrics.collect()` 使用经验证的关联解析 fastp 记录，R1/R2 分别读取真实字段。保留冲突检测、来源版本与缺失原因。
- 不使用 `TCR_` 模糊别名，不对半拆总 reads，不从 Clean 或另一条链反推 Raw。
- 同时检查 trace 上游计数读取链路，避免新生成 trace 延续相同缺失。
- 新增原始身份列与旧汇总兼容；若旧目录无法唯一关联，保留 N/A，不自动修补。

主要文件：`Igblast_base/pipeline/02.run_fastp.sh`、`scigblast/stage_metrics.py`、`scigblast/input_manifest.py`，以及经检索确认受相同关联影响的 trace 读取函数。Pig 仅在核实相同问题后做兼容修改。

### 4. 更新现有报告

- 优先从现有 fastp JSON 和阶段回执重建派生阶段汇总，不重扫原始 FASTQ、不重新 IgBLAST。
- 数据修复不能仅执行 HTML 换皮。提供或复用受校验的定向刷新入口，更新阶段表、summary、相关 Excel/图表和清单，随后重导出 HTML。
- 先输出独立验证版本，核对成功后才发布。已有报告数据与生产中间结果不就地猜配覆盖。
- 源数据、阶段解析实现和绘图实现变化须使相关缓存失效；纯 UI 调整用 `analysis.repertoire.export_html`，不触发全量统计。
- 保留本轮开始前四个 Web 引物配置文件的未提交改动及用户数据，不混入清理或部署。

### 5. 多样性模块去重

- 当前静态输出包含六项核心指标的比较图及独立 Simpson evenness 图，交互端依据文件名划分指标；单样本图还按结果组分别生成。仅凭代码尚不能断定用户当前报告重复属于哪一种路径，实施前检查该报告实际 figure 清单及筛选后的图身份。
- 在图元数据中明确样本、链、结果 group_id、指标集合与单样本/比较范围。现有通用 `render.save()` 未保留 group_id，需补齐，防止不同结果图在交互时读取同一范围。
- 单样本只显示一套对应指标，多样本显示一套比较视图。每个“样本＋链＋结果＋指标”仅呈现一次，不能按标题盲目去重或误合并不同来源。
- Simpson evenness 保留原指标身份与值，纳入同一指标浏览区域，不额外重复完整模块。静态图仅作不支持交互时的备用展示。
- 筛选后重新计算有效分页，不保留空页及重复图容器；不修改多样性计算结果。

主要文件：`analysis/repertoire/render.py`、`render_metrics.py`、`repertoire_metrics.py`、`report_html.py`、`assets/charts.js`、`assets/report.js`。

### 6. 基因匹配简化为一张表

- 顶部仅保留样本和链选择。支持单选、多选、全部，模块筛选保持独立。
- “按样本 / 按引物”使用轻量切换，默认按样本，按引物时才显示引物选择；存在存疑组时再显示相关入口。
- V / J / C 采用互斥标签，替代并排三张卡片。搜索、全部/已匹配/未匹配状态选择放在表上方一行。
- 一张全宽紧凑表，单一上下文显示基因与状态；多样本时增加样本、链列，多引物时增加引物列，存在多个结果/参考或存疑来源时保留必要身份，避免同名基因错误混合。
- 家族通过轻量分组行与分隔线区分，IGHG4、IGHG5 等仍归 IGHG，不嵌套多层卡片；家族跨页时保留上下文。
- 整个工作区只有一套分页，默认每页 10 条基因记录、可自定义。不为每个样本/每个区分别设置分页。
- 保留唯一“下载基因匹配总表”按钮，覆盖全部样本/引物，不受当前筛选及分页影响。
- 缺少参考来源与确实未匹配保留不同语义，不将无法评估记录标为未匹配。

主要文件：`analysis/repertoire/assets/report.js`、`assets/report.css`、`report_html.py`。不改变底层匹配统计或 CSV 契约。

### 7. 样本信息强化分组

- 当前表格仅在类别变化时添加 `category-start`，同类别不同样本的视觉区分不足。
- 以完整样本身份分组，同一样本多条链连续展示，不按链类别把 MIX 拆散。单链样本保留类别排序，多类别样本独立分组并保留逐链对应关系。
- 样本名加粗、样本组交替使用白色和低饱和浅底色，组间增加清晰分隔线。颜色按样本组交替，不逐链交替，不引入彩虹配色。
- 同一组内不重复堆叠大标题，链与引物组逐行对齐，长名称自然换行。桌面可合并样本名单元格，移动端仍保证每行上下文可理解。
- 保留默认全部展开、固定高度滚动/拖动、固定表头；浅色与夜间主题均需区分清楚。

主要文件：`analysis/repertoire/report_html.py`、`assets/report.css`，必要时调整 `workbook_overview.py` 的报告专用排序，避免影响 Excel 原统计。

### 8. 科研观察与交互补充

- 每个模块保留紧凑的当前范围提示，明确所选样本、链及原组/存疑组，结果区靠近筛选区。模块间筛选仍独立，切回保持状态。
- 无关或只有一个有效选项的筛选不占用大块空间，必要上下文以静态文字显示；按引物模式、存疑组、多个结果等复杂入口按需出现。
- 图例点击状态明确显示，提供当前图恢复图例的入口，避免用户忘记隐藏类别后误读。缺失、零值、不适用保持不同语义。
- 样本比较统一样本顺序，指标维持各自量纲；同链比较默认同一坐标范围，跨链比较显式区分。基因对齐仅在参考来源相符时启用。
- 提示框统一显示样本、链、指标值，百分比指标补充分子和分母。正文减少重复口径文字，详情放在已有统计口径区域，不额外叠加提示面板。
- PNG 操作紧贴对应图，完整总表下载放在模块标题旁，下载名称带样本/链/指标。避免多处出现语义不明的“下载”。
- 展开图、切换样本、恢复筛选后尽量保持阅读位置与键盘焦点；标签切换显示当前选择，隐藏内容入口可辨识。
- 当前页之外的图不创建 ECharts 实例，切换销毁旧实例；长列表分页，避免复杂 DOM 和大图同时渲染。
- 不增加自动科学结论、综合评分或未经认可的异常阈值。
