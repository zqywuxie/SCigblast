# 新建任务与任务详情 UI 布局优化方案

日期：2026-10-21。状态：已实施并完成本地验证，待部署。

## 目标与范围

面向实验与数据分析人员，让“输入什么、处理哪些样本、当前到哪一步、接下来做什么”更易理解。统一灰白底、细边框和蓝色主操作；错误与警告保留语义颜色，取消流程装饰色。复用现有原生 JavaScript、模板与样式。

本轮包含新建任务弹窗，以及详情页顶部、阶段进度和运行概览／Match 审核／实时日志／输出文件／参数与记录五个 Tab。reMapping 继续隐藏不适用的 Match Tab。

保持任务 API、权限、分析参数、阶段顺序、审核规则、文件内容与输出契约。保留当前工作区尚未提交的 Pig 目录布局和运行时长修改。

## 一、新建任务窗口

### 布局

采用“紧凑流程选择 + 单一正文滚动区 + 固定操作栏”。保留单页表单，便于反复核对路径、样本和 Chain。

- 弹窗桌面最大宽度约 1080px；固定标题与底部操作区。移除 290px 左侧流程栏，流程选择移至正文顶部，桌面五个紧凑选项横排，窄屏换行；每项显示名称，当前流程另显示一句输入说明。
- 正文按“数据来源与路径 → 样本与 Chain（适用时）→ 可选设置 → 检查详情”排列。移除重复的当前流程卡片及步骤装饰，让扫描列表使用全部可用宽度。
- 流程选择随正文滚动，不在手机上长期占据顶部。正文为唯一主要纵向滚动区；目录、reMapping 样本通过分页限制高度，不再套独立纵向滚动区。
- 来源选择仅在 Base/Pig 显示，保持 Submission 为当前默认；IR/10X 保持 Submission 模式；reMapping 显示 CSV 格式与 Human 说明。路径使用完整宽度，浏览按钮靠右，校验反馈紧随对应字段。
- 数据集名称保持可选且便于发现；Barcode 覆盖与输出位置继续折叠，说明默认行为，不增加参数。

### 样本与 Chain

- 将“扫描”“批量指定 Chain”“搜索与选择”分成三组，直接显示未扫描、扫描中、空结果、异常项、未指定 Chain 等状态。
- 目录样本桌面行布局为选择框、样本名称与相对来源、Chain 摘要；文件完整路径展开查看。移动端转为上下排列。保留逐样本改名、多链覆盖和不可变 row.id。
- 保留现有 20 项分页、有效样本默认全选及跨页选择。按钮明确标注“全部有效样本”“清空全部选择”“将 Chain 应用到全部已选样本”，搜索和分页不改变全局作用范围。
- 搜索按显示中的样本名称与相对来源匹配；新建重置、流程／目录上下文变化后清除旧搜索，避免新扫描看似缺少样本。纯搜索、分页不改变任务请求，也不使已完成的配置检查失效。
- reMapping 增加搜索与分页前，先把样本清单和选择改成独立完整状态；不能继续以当前页 DOM 作为完整选择清单。保持发现 IGH 时默认 IGH、全部样本默认选中及样本／链交集规则。范围摘要同时显示已选样本与实际处理文件数。

### 操作与状态

- 底部始终显示处理范围或不能创建的具体原因；右侧保留取消、检查配置和主操作。主操作继续区分“创建任务并执行 Match”“创建任务并开始分析”“保存配置并重新 Match”。
- 检查状态区分未检查、检查中、通过、存在问题、配置已改变；错误定位到字段，展开折叠内容并聚焦。沿用后端创建时校验，不新增必须先点击检查的业务限制。
- 统一由提交中、扫描中及业务就绪状态决定控件状态。先读取完整请求快照，再锁定相关控件；提交期间禁止重复请求，扫描或选择回调不能重新启用提交。失败保留输入与选择并恢复控件。
- 保留 generation 防止旧扫描／校验响应覆盖新配置。区别影响请求的配置变化与纯浏览变化，保留目录重新 Match 的流程、路径和来源锁定。
- 沿用现有按钮选择与 aria-pressed；补齐内部隐藏 select 的样式与焦点规则。焦点循环覆盖 summary，保持文件浏览与 Submission 编辑器关闭后的焦点返回。
- 关闭再打开仍按现有规则重置，不增加草稿存储或额外确认弹窗。

## 二、任务详情页

### 当前问题与依据

`web/templates/job.html:6–10` 在 Tab 前依次排列标题、状态／按钮、刷新提示、四张信息卡和完整阶段网格。`web/static/job.js:49–56` 同时在标题和概览显示 nextStep，在 hero 与信息卡重复状态。长名称、8 阶段流程或手机布局会进一步挤压工作区。已有 Tab 键盘切换、结果状态恢复与下载预览较完整，本次保留这些能力，重点调整信息层级。

### 从顶部到工作区

```text
返回任务列表                         任务操作
任务名称                 状态标识    主要操作
流程 · Job ID · 操作者 · 创建时间
本次运行时长     当前阶段     已完成阶段 / 总阶段
下一步提示 / 异常原因（需要时）
阶段完成比例                      展开全部阶段
------------------------------------------------
运行概览 | Match 审核 | 实时日志 | 输出文件 | 参数与记录
当前 Tab 工作区
```

- **任务标题区**：增加明确的返回任务列表入口；任务名称为主标题，长名称自然换行。流程、Job ID、操作者、创建时间作为次级信息，不再各占大卡片。状态标识只展示一次，更新时刻收为轻量文字。
- **运行摘要**：突出本次运行时长、当前阶段和阶段完成数。保留服务器时长 + performance.now() 插值、按秒更新及 attempt 变化重新计时，不能改成“创建到现在”或累计时长。未知值明确显示未知，不补造数据。
- **操作层级**：按现有任务状态保留审核继续、停止、续跑、编辑重新 Match、删除及恢复进程停止能力。当前最相关操作为主按钮，编辑与删除降为次要操作；保留既有确认与权限判定。查看日志／结果等导航只切换 Tab，不发起任务操作。待审核状态突出审核入口与未完成条件，不复制出两套独立确认逻辑。
- **提示区**：只保留一处下一步说明；失败原因与日志入口放在可见位置，不藏入阶段展开区。连接中断提示保留，显示最近成功更新时刻，不冒充实时状态。
- **阶段进度**：默认显示紧凑的当前阶段、阶段完成比例和完成数；“展开全部阶段”显示原阶段名称、顺序与完成／当前／未开始状态。保留展开选择，轮询不重置。只能依据 API 已知字段显示阶段，不推断失败阶段，也不把阶段比例解释为预计剩余时间。
- **Tab 导航**：紧接紧凑摘要，随页面滚动吸顶。桌面清晰平排，手机单行横向滚动，选中项自动进入可视范围。reMapping 保持四个适用 Tab，不强加 Match。

### 五个 Tab 的具体布局

| Tab | 布局与交互 |
| --- | --- |
| 运行概览 | 展示输入来源、处理范围和结果说明；仅使用已经取得的真实配置／统计。路径、Submission 副本、清单版本、开始结束时间、退出码等按需展开。长样本范围折叠，不铺满页面；不再重复顶部状态与下一步提示。 |
| Match 审核 | 第一层为全部记录的标注进度及继续分析条件；第二层为搜索、错误／未标注筛选、下一条未标注、刷新和下载；第三层为跨页已选数量和批量标注；下方为审核表格。“全选本页”与跨页已选总量分开说明。表格允许自身横向滚动，未识别登记样本作为次级区域，数量和异常提醒保持可见。保留 revision 校验、失败保存重试、筛选变更清空选择、全部记录完成标注才能确认，以及 OK／ERROR 与待补资料的原语义。 |
| 实时日志 | 单一紧凑工具栏展示来源、暂停刷新／继续刷新、自动滚动及复制；日志正文获得主要空间。暂停刷新与关闭自动滚动分别说明。保留当前增量拉取、截断上限、attempt 重置及仅在日志 Tab 拉取的策略，不增加轮询频率。更新不抢焦点；关闭自动滚动时不改变阅读位置。 |
| 输出文件 | 保留已有样本文件列表、状态过滤、搜索、分页、下载和数据预览。reMapping 以最终 UMI 文件为主，其他阶段报告为次要折叠区；其他流程保留报告导航。桌面宽屏列表／预览并排，较窄屏上下排列。压缩重复标题与说明，统一列表／预览工具栏、按钮与留白；保留缺失、空结果、失败、未完成与归档的区别。继续隐藏不需要展示下载的转换 FASTA，不修改任何结果文件。 |
| 参数与记录 | 操作时间线与配置快照形成明确的两个区域，桌面两列、手机单列，手机先时间线再参数。直接展示已有操作者、时间、动作与说明；长路径和参数按需展开，不增加不存在的统计或审计字段。 |

### 状态、滚动与无障碍约束

- 保留初始 Tab 优先级：现有 #match／#artifacts 深链 → 当前用户／任务保存偏好 → 成功或归档默认输出文件 → 其余默认概览。轮询、任务状态改变和刷新不能强行切换用户正在查看的 Tab。
- 保留 Arrow／Home／End 和 roving tabindex；补齐 Tab 按钮 ID、面板 role=tabpanel、aria-labelledby 及隐藏面板焦点控制。鼠标与键盘切换保持导航焦点；由“查看日志／结果”触发的跳转将工作区带入视野并聚焦对应标题，尊重减少动画偏好。
- 页面主体滚动，数据大表和日志保留必要的自身滚动容器。吸顶导航、结果预览 sticky top 和 scroll-margin 使用一致偏移；导航保证单行，缩放或尺寸变化时核验高度，避免遮挡预览标题、下一条未标注与错误定位目标。
- `refresh()` 不再每次都整体替换标题操作区、信息卡、阶段和概览。以状态／内容签名决定是否更新结构，普通时间和计数局部更新；稳定保留焦点、展开状态、文本选择与滚动位置。仍沿用现有 5s／30s 详情轮询和页面可见性规则。
- 沿用 sessionStorage 中用户／任务隔离的现有 Tab、结果筛选、文件和字段偏好；不增加持久化结果行、游标、下载选择或临时 URL。attempt 改变继续清除旧执行和结果浏览状态。

## 实施文件与顺序

1. `web/templates/index.html`、`web/static/style.css`：弹窗结构、单滚动布局、固定页脚和响应式。
2. `web/static/index.js`、`web/static/directory-input.js`：完整选择状态、搜索分页、范围摘要、提交与检查状态。
3. `web/templates/job.html`、`web/static/job.js`、`web/static/style.css`：顶部摘要、紧凑阶段进度、吸顶 Tab、局部更新与五个 Tab 的工具栏。
4. `web/static/results.css`：在保留已有结果交互基础上统一密度、响应式和 sticky 偏移，不重写结果模块。
5. 更新 `web/README.md` 与 `AGENT.md` 中对应交互约定。

共享样式限制在新建弹窗与详情页作用域；整理所涉及旧覆盖规则，不改动登录、账户与首页任务列表。分块实施并审查请求快照，避免把视图调整混入分析逻辑。

## 验证安排

- 实施时使用隔离临时测试服务与合成数据，通过 Playwright 验证；不提交真实分析、不重启在线服务。
- 新建任务覆盖五条流程、Base/Pig 两种来源、目录重新 Match、默认 Barcode 与覆盖值。比较同一输入选择在改造前后的请求，字段与含义一致。
- 覆盖 0／1／多页样本、长路径、同名样本、异常配对、跨搜索分页选择、改名、多链及无交集；分页后提交不能丢失非当前页选择。
- 模拟迟到的扫描响应、检查后改配置、重复提交、请求失败恢复；仅搜索和翻页不使检查结果失效。
- 详情覆盖排队、运行、待审核、成功、失败、停止、中断与归档状态；按钮出现条件和服务端权限与原有行为一致。额外核验恢复进程停止入口不会被次要操作收纳隐藏。
- 覆盖五个 Tab，reMapping 四个 Tab；深链、初次落点、用户偏好恢复、手机导航、键盘切换及局部失败重试正常。等待多次详情轮询后，焦点、阶段展开、输入和阅读位置保持稳定。
- 验证 Match 跨页标注／revision 变化／保存失败／确认门槛；日志暂停、自动滚动与 attempt 切换；结果筛选、字段、文件版本变化、游标读取、缺失与空结果、当前页选择下载、归档入口及预览弹窗。保留已有页面级状态隔离和下载契约。
- 本次运行时长覆盖运行中增长、完成固定、等待审核固定、排队未启动、排队取消及重试重新计时；不能因布局调整改变语义。
- 桌面 1440×900、1366×768、平板 768×1024、手机 390×844；检查长名称、200% 缩放、焦点可见、无页面横向溢出、底部主操作可达。大表格允许在自身容器横向滚动。
- 实施阶段运行 JavaScript 语法检查及现有 `test_directory_input.py`、`test_mapping.py`、`test_job_runtime.py`、`test_workflow.py`、`test_mapping_results.py`、`test_artifact_download.py` 中相关回归；仅对实际新增或修正的行为补充验证，不增加样式快照堆叠。

## 完成标准

常见任务在 1366×768 首屏即可看见关键状态、运行时长、主要操作和 Tab 入口，并留出工作区内容；手机无需穿过大段重复卡片才能切换功能。新建任务能清楚解释输入要求、实际选择范围与未满足条件。相同输入选择生成相同任务请求，现有分析流程、审核及下载行为保持一致。交付桌面和手机的关键状态截图与回归结果，再根据用户指令推送或部署。
