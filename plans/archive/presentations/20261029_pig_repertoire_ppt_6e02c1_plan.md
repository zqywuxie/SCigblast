## 1. 汇报目标与边界

围绕三个问题展开：本批文库能获得什么组库信息；Data point、isotype、V/J gene frequency 与多样性指标如何互相解释；哪一份 Heavy 最适合后续分析及依据是什么。

比较分为技术表现与组库特征。丰富度、均匀度、克隆扩增、SHM、isotype 组成没有普适的“越高越好”。在确认生物来源、实验条件和重复前，只做描述性文库比较，不宣称引物的因果效果，不添加显著性星号。

## 3. 正式分析前的口径核验

必须找到这批报告实际使用的输入、脚本版本、参考库版本、过滤参数与依赖版本。下列是当前本地实现中发现的风险，尚不能证明该报告一定由这些文件生成：

1. `E:/Desktop/project/SCigblast/preprocess/models/preprocessing.py`：删除 sequence_id 后，以相同 sequence 出现次数形成 umi_counts。该逻辑本身不能证明 UMI 分子去重，也不能等同细胞数。核对本批实际流水线与输入是否已经 UMI 去重，再确定正式图轴名称；未确认前用“报告计数（原字段 IGH_umi_counts）”。
2. `.../preprocess/models/diversity.py`：最大克隆比例按 CDR3aa 聚合，Shannon/Pielou/Gini/Simpson 按输入记录行及其权重计算。PDF 却统一描述为 CDR3 peptide distribution。需确认统计类别、对数底和库版本；不直接将现有 Shannon 与 uCDR3 组合解释或换算有效克隆数。
3. 同文件 D50 使用累计权重 <=50% 的记录数，未包含跨越 50% 的那一条。重算时使用达到至少 50% 所需的最少类别数/类别总数，并保留旧值、修订值、口径和版本记录；不能悄悄替换原报告结果。
4. `.../preprocess/models/shm_calculate.py`：V_SHM 为错配+插入+缺失数量的平均值，V_SHM_ratio 才是比例。H 的 23.57 不能写成 23.57%；原表 V_SHM_ratio 为 0.07909。全比对区差异含重排区和参考不确定碱基等因素，不能直接当作纯 SHM。isotype 汇总使用 mean(SHM × weight) 的实现需核验分母，未核验前不作主结论。
5. `.../preprocess/models/csr_calculate.py`：同 CDR3aa 的跨 isotype 共现及权重组合不证明转换方向、真实事件次数或速率。图文使用“跨 isotype 共享 CDR3”，不绘制未经支持的转换箭头。
6. `.../preprocess/models/expression.py`：isotype 比例分母为满足其过滤条件、C 注释可用的 IGH 权重，并非全部输入 reads。应补 C 注释成功/缺失/歧义比例；未观察到的 subclass 不自动填成已确认生物学 0。
7. C 区参考存在完整与部分序列，短 C 片段、同源 subclass、引物残留可能影响注释；核对覆盖长度、identity、多个相近命中及数据库命名。不把“引物名 IGHM”直接视为“该 read 的 c_call 必须 IGHM”。

引物统计继续沿用已获用户认可的主口径：5′起点完整精确匹配，IUPAC 简并规则，read N 不视作确定匹配；分母是该样本全部有效 FASTQ reads，唯一/歧义/未匹配互斥。N1 的位置偏移诊断单独展示，不混入主统计，不直接认定错标/污染/失败。

## 4. Heavy 的选择方法

采用分层判定，不制作任意加权综合分数，也不将本批单样本观察推广为方法学排名。

1. **可比与可信**：确认样本来源、实验目标、数据与引物对应、统计单位及 C 注释可靠性。N1 保留在比较中并标注待核验，不因低精确匹配率直接淘汰。
2. **可用产出**：同一过滤和计数口径下比较有效产出、目标链比例和有效 CDR3 数；只有上下游数据确属同批且单位对应时计算产出率。
3. **可比深度的覆盖**：获取逐 CDR3/克隆丰度后，在 Heavy 组内采用共同深度重抽样，比较丰富度、克隆集中度与 V/J 检出。提供抽样不确定性，不能当作生物学重复误差；不把全体样本强行降到 L 的低深度。
4. **用途匹配**：广谱分析看可重复的基因与 isotype 捕获；特定 isotype 研究看目标有效产出。低最大克隆或高 Shannon 不自动表示更优文库。
5. **输出明确结论层级**：完成核验后选一份主展示 Heavy，并写出替代候选及限制。若只提供现有汇总材料，N2/O1 可作为下一步优选候选，不能宣布唯一最佳。N2 起点匹配较高，O1 报告 uCDR3 较多、最大克隆比例较低，这些单项优势仍不足以互相取代。

## 6. 指标教学的重点

| 指标 | 要解释的内容 | 主要限制 |
|---|---|---|
| 报告计数、有效比例 | 得到多少可用数据 | 先确认 reads/UMI/sequence 权重来源 |
| uCDR3 | 检出多少不同 CDR3aa | 不等于完整克隆谱系数，受测序深度影响 |
| Shannon | 丰富度与分布均匀性共同作用 | 类别、权重与对数底必须一致 |
| Pielou | 相对于该类别数的均匀程度 | 与 Shannon 使用同一类别全集 |
| Gini | 丰度集中在少数类别的程度 | 高集中可能是生物学扩增，不必然是技术差 |
| Simpson | 此处若为 1−Σp²，越大越多样 | 不与集中度 Σp² 或 inverse Simpson 混淆 |
| D50、Top clone | 达到累计50%需要多少类别、最大类别占比 | 明确边界行、克隆定义和百分数单位 |
| V/J 频率 | 基因覆盖与使用偏好 | 参考库、注释歧义、深度与引物捕获影响 |
| isotype | C 区注释后的类别构成 | 转录本/reads 比例不等于细胞比例 |
| V_SHM_ratio | 相对参考序列的差异负荷 | 胚系缺失、测序误差、indel和N处理需核验 |
| CSR 代理量 | 不同 isotype 的 CDR3 共享 | 不提供方向或真实转换速率 |
