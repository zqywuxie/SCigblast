# 猪 IGHM / IGHD 歧义的分析建议

本文件是分析设计，不表示已对当前数据完成 IGHM/IGHD 歧义判定，也没有启用新的 C 区归属阈值。现有服务器四样本报告来自候选上限 1 的运行，不能以单个 c_call 推断不存在其他命中；本地上限 2 与候选核查代码尚未部署。此前将两个候选简单解释为 Top1/Top2 两套确定表达量的建议不适合作为歧义问题的最终解决方案。

## 需要先区分的问题

- AIRR 汇总 call 中的逗号列表是等价最佳匹配，不是完整的第一名、第二名得分表。只看其排列顺序不能证明哪个 Isotype 更可信。
- 同一基因的多个等位基因不同于 IGHM 与 IGHD 两个基因。`num_alignments_C=2` 最多报告两个参考命中，两个位置可能均被同一基因的等位基因占据，不能保证同时看到 IGHM 和 IGHD。
- `c_call=IGHD*...` 指恒定区；`d_call=IGHD1*...` 等是 D 片段，不能混为一类。
- 一条 read 命中两个参考不是生物学共表达证据。IgM/IgD 可使用相同 VDJ，因此相同 CDR3 也不能替代 C 区证据判定 Isotype。
- 目前没有验证本批样本的歧义来源。应核查模板中的 C 区长度、具体覆盖的外显子/保守片段、区分位点、参考完整性、测序不确定碱基以及残留引物，而不能直接宣称猪的两个完整 C 区无法区分。

## 建议的主结果与核查结果

主结果保留明确的 IGHM、明确的 IGHD、`IGHM/IGHD unresolved`、其他 Isotype 和无可用 C 注释。对于只有不足长度或缺少区分位点的 C 证据，记录 `insufficient_C_evidence`，不能只因为有一个最高命中就宣称已确定。

逐条核查表建议保留样本、query ID、引物归属/剪切状态、原始 c_call、各不同 C 基因的最佳参考、得分与差值、identity、实际比对长度、query/reference 起止位置、是否覆盖区分位点以及最终分类原因。没有实测的字段留空，不能从 AIRR 的一个 c_score 推造第二候选得分。

先去除已识别引物、再用实际模板序列判断 C 区；当前“未匹配引物保留原序列”策略保持，但这类记录在核查中单独标记。引物组名和引物设计意图仅是辅助证据，不能用来强制分配 C 基因，否则无法评价引物本身的扩增偏好。

得分差、长度、覆盖率、区分位点质量阈值应通过真实阳性对照/人工检查校准；不直接采用任意的差值或 identity 数值。此前用于其他引物组复核的 50% 是样本唯一引物匹配率阈值，与 C 区归属判定没有关系。

## 图表与分母

1. 全样本、逐引物的 C 构成图：包含 unresolved 和无 C 注释类别；Reads 比例统一以相应范围全部有效记录为分母。样本范围使用全部最终有效 reads，引物范围仅使用可追溯到该引物的记录，不重复分配多引物命中。
2. IGHM/IGHD 核查图：得分差、比对长度与覆盖区段的分布，以及每组引物中 unresolved 的比例。等分和证据不足必须可见，不能被第一名/第二名的名称遮盖。
3. 敏感性分析：展示未定数据全部归 IGHM 与全部归 IGHD 两种假设的影响；这是边界分析，不是重新确认两个 Isotype 的表达。

例如样本有效 reads=1000，明确 IGHM=500、明确 IGHD=300、两者未定=150、无 C 注释=50。主图是 50%、30%、15%、5%；对于这150条未定记录，IGHM Reads 占比的可能范围为50%–65%，IGHD为30%–45%。两个上界不是能同时成立的一套组成，不能相加使用。

uCDR3 需按集合计算：IGHM 的确定克隆集合为 M、未定集合为 A，则数量下界是 |M|、上界是 |M∪A|，而不是直接将未定 reads 数加到克隆数。每种假设下重新计算现有 uCDR3 百分比，避免重复 CDR3 或变化的分母造成错误。

C 区不确定不应删除仍有有效 V/J/CDR3 的整条记录，原阶段流程、过滤和 Treemap 范围保持。V/J 的归属与 C 区核查独立。

## 补充证据与实施顺序

先核查当次实际参考清单与代表性 IGHM/IGHD 命中；如需获得完整排名，补充带各命中得分/坐标的原生命中表，或对已保存模板中可识别的 C 区做专门的 IGHM/IGHD 比较。不得从旧单命中 TSV 恢复不存在的第二命中，也不要未经说明将完整 VDJ 全流程运行两遍。追加分析采用新版本目录，保留原始结果与归属记录。

当前建议需要先确定并校准判定标准；没有自动重跑生产任务、改变数据库、以引物名称代替基因证据，或把未知记录补为零。
