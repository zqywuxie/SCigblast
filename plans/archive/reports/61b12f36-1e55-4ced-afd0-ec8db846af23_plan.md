# HTML 报告前端操作体验优化方案

日期：2026-11-03。状态：用户授权后已完成第一期及图表放大功能，未推送部署。

实施结果：`outputs/a93f6d1c/report.html`（v31）。`data_validation.json` 验证20份内嵌表与v30逐项一致；`browser_validation.json` 验证局部重置、搜索/焦点、13/50样本列表、15引物搜索、上下分页、主题/模块图形视图、原实例放大、导出反馈、手机、键盘与离线。模拟数据仅用于临时交互验证，未进入交付HTML；原pipeline结果未修改。

## 范围与依据

审阅当前 v30 代码、`outputs/72c4d9a1/report.html` 及已有桌面/手机截图。本轮没有重新运行浏览器测试。目标是减少操作歧义、缩短查看路径、改善长图阅读与导出反馈。

已有功能继续沿用：顶部模块标签、模块独立筛选、总览默认全样本、逐引物基因组成单样本、Expression/Unique CDR3 左右对照、同链对齐、PNG/CSV 离线导出、最多7图、基因列表默认10条且可调整。本轮不调整统计计算。

## 第一期：操作一致性与阅读布局

### 1. 修正重置范围（P1，代码确认的问题）

现状：`report.js:252` 调用 `ReportCharts.resetSelections()`；`charts.js:231` 清空所有模块图例状态。与此同时，当前基因匹配的 `reference-scope` 未恢复为整个样本，多选搜索词也未清空。操作位置在当前模块，实际影响范围却不一致。

方案：
- 按钮改为“重置本模块”。集中定义模块默认状态，首次进入与重置复用同一份定义。
- 重置当前模块的样本范围、链、引物、阶段、存疑组、搜索、比较方式和分页；基因匹配恢复“整个样本”和每页10条。
- 总览/样本产出恢复全部适用样本；其他模块恢复首个适用样本。逐引物组成恢复当前默认样本及有效引物。引物匹配默认 Mapping 阶段，Mapping 效率始终 Mapping。
- 图例显隐、缩放/色条视图按模块与图形上下文保存；只清理当前模块。Expression/Unique CDR3 同一对图的图例联动继续保留。
- 更换样本/基因区后按新上下文初始化图形，主题切换则保留当前图形视图。

### 2. 明确样本选择与搜索（P1）

现状：“单选”模式可选择“全部样本”，含义不一致。多选搜索仅隐藏列表项，“全选”却选中全部适用样本。每次勾选会整体重建选择器和图表。代码还显示：超过12项时 `searchable()` 创建单选搜索框，随后 `samplePicker()` 删除除 select 外的所有子节点，使预期的长列表搜索被移除；此项需在实施时用13项以上数据验证，不应描述成当前8样本出现重复搜索框。

方案：
- 样本范围明确为“全部 / 单选 / 多选”。单选下拉只包含具体样本；全部状态显示“全部适用样本”。逐引物基因组成仅提供单选。
- 短列表保留现有样式化下拉；长列表搜索由选择器统一维护，重绘时保留输入及焦点。
- 多选即时生效，不增加确认步骤。勾选时保留列表滚动、搜索词与焦点，避免重建整个选择器；必要时合并短时间内的连续图表更新。
- 无搜索词时为“全选”；有搜索词时为“选择搜索结果”，仅追加当前结果，保留此前选中的其他样本。“清空”明确清空全部选择。
- 搜索无结果时展示可清除搜索的简洁空状态；空选择显示“请选择样本”，不能悄悄替换为全部。
- 搜索词随模块独立保存；不让上一个模块的查询过滤新模块列表。

### 3. 压缩首屏层级与重复标题（P2）

现状：报告头、导航、展开的样本表、模块标题、子标签、说明、筛选和图卡逐层占据高度。图卡标题与图内标题经常完全相同，且存在多层边框。

方案：
- 任务名与报告信息使用紧凑头部，主导航仍在上方。
- 样本信息保留在总览最开始；桌面首次打开保留展开，手机默认收起，并记住本次阅读的展开状态。缩小表格行间距，不新增总数卡片。
- 筛选集中在模块标题下的一组自适应控件中，仅显示当前适用项。范围摘要只补充控件没有完整显示的内容，避免再次重复“已选2个样本”。
- 统计口径用明确的折叠入口置于图表上方。数据缺失和存疑分析提示保持可见，不与普通说明一起隐藏。
- 样本/链/引物上下文只显示一次；图内保留英文标题，去掉图外语义完全相同的标题。成对图保留共同分组和各自指标，PNG仍包含完整身份信息。
- 弱化外层面板与成对图的重复边框，统一控件高度、字号、间距及选中状态，不引入新装饰色。

### 4. 改善长页面导航和翻页（P1）

现状：主导航为静态布局；图表翻页按钮仅位于画廊上方。模块和图表页切换没有对应滚动定位，长图需要反复返回页面上方。

方案：
- 顶部模块标签做紧凑吸顶；不固定整个报告头和全部筛选项，避免占据阅读空间。
- 手机标签使用单行横向滚动，确保当前项可见；不改为侧边栏。
- 切换模块或子模块时定位到模块标题；图表翻页时定位到画廊起点。普通筛选、连续勾选和主题切换保留当前位置。
- 多页画廊底部增加同源分页控件及“返回筛选”；只有一页时不展示禁用的上一页/下一页。
- 顶部与底部分页共用同一状态；模块原有分页记忆保持独立。
- 完善标签的选中语义、键盘操作与焦点保持；吸顶导航不能遮挡被定位的标题或键盘焦点。

### 5. 宽图和导出的可发现性（P1/P2）

现状：手机宽图已经能够横向滚动，但截图中超出屏幕的内容缺乏明显提示。PNG导出只暂时禁用按钮，失败没有界面反馈；CSV没有可导出行时直接返回。

方案：
- 只有图形实际超宽时显示轻量边缘提示或“左右滑动查看”；到达边缘时更新提示。整页保持不横向溢出，长标签不强行缩小或随意截断。
- PNG按钮依次显示“正在生成…”与“已发起下载”；失败显示简短原因及重试。浏览器不能确认保存完成，因此不显示“已保存成功”。
- CSV无可导出数据时明确告知当前无显示数据，并提供恢复图例/筛选的操作路径。
- 状态提示放在当前图卡附近，通过 `role=status` 告知辅助技术；不弹出成功确认对话框。
- 原有PNG/CSV范围、图例筛选、分母及离线能力保持一致。

## 第二期：集中查看图表（P2）

在图卡提供“放大查看”，适用于密集基因图、长引物名和左右指标比较。使用对话框移动当前图表节点，避免另建一套图形实例；进入后按可用空间 resize。关闭、Escape 与键盘焦点回到入口，并保留图例/缩放/滚动状态。导出仍对应放大窗口中的当前图。活动实例不超过既定上限，手机优先使用整屏可滚动查看。

## 关键文件

- `analysis/repertoire/assets/report.js`：模块默认值、样本选择/搜索、局部重置、导航定位、上下分页、反馈和可选放大。
- `analysis/repertoire/assets/charts.js`：按模块管理图例/缩放状态、导出返回结果、放大时复用实例。
- `analysis/repertoire/assets/report.css`：紧凑层级、吸顶导航、响应式、宽图提示、焦点和导出状态。
- `analysis/repertoire/report_html.py`：语义结构、模块控件、分页/状态容器；升级HTML版本，让平台导出使用新界面。
